**Coral Bay Heat** — a top-down open-world crime game in vanilla JavaScript and canvas, set in Coral Bay, an original sun-soaked coastal city. Explore on foot and by car: a full road grid with traffic that follows lanes and turns at intersections, crowds of pedestrians, named landmarks (Vera's Customs, First Bank of Coral Bay, St. Marina Hospital, Bay Armory, Coral Bay PD, the marina and its pier). Steal any car you can reach — including the teal Comet on Ocean Drive — run Vera's three-mission story (steal the Comet, move a hot package, drive Vera to her boat), pick up repeatable courier work, and manage a five-star wanted level: police spawn, pursue, ram and shoot, and bust you if they corner you on foot. Earn and spend cash on heals, repairs and ammo, grab pickups, and watch it all on a HUD with a live minimap. Progress saves to localStorage. No libraries, no build step, no network: synthesised WebAudio sound, seeded procedural city, one job per source file.

## Run it

```sh
node serve.ts        # then open http://localhost:8080
```

Hand it in (copies `game/` and `screenshots/` to the output dir and writes `dossier.json`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
